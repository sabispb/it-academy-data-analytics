# Sprint 12 - Consum de dades des d'una API REST

Aquest directori recull el material del *Sprint 12* del bootcamp de **Data Analytics** de l'IT Academy, centrat en el consum de dades mitjançant APIs REST.

## Contingut

- `S12_PlanasBonell_Sabina.ipynb`
  - Notebook Jupyter amb la resolució dels problemes plantejats.
- `api_requests_realpython.ipynb`
  - Notebook de proves per practicar l’ús de la llibreria requests i entendre el funcionament de les peticions HTTP.
- `data/`
  - Carpeta destinada a emmagatzemar dades obtingudes de l’API.
